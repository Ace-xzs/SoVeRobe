# SoVeRobe

SoVeRobe is a Flutter fashion-discovery app for collecting outfit ideas and
finding inspiration for your personal style.

## Getting started

1. Install Flutter and a supported mobile or desktop toolchain.
2. Fetch dependencies with `flutter pub get`.
3. Launch the app with `flutter run`.

The app opens on the SoVeRobe welcome screen. Tap **Start exploring** to browse
the inspiration feed and save looks.
